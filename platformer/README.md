# Platformer Game

このプロジェクトはPythonで実装するプラットフォーマーゲームです。

## 概要

プラットフォーマーゲームの基本的な機能をPythonで実装します。各関数に対してテストを作成し、テスト実行を学びます。

## セットアップ

1. Python 3.8以上をインストールしてください。

2. 依存関係をインストール：

   ```bash
   pip install -e .
   ```

3. テストを実行：

   ```bash
   pytest
   ```

4. ゲームを実行：

   ```bash
   python -m platformer.game
   ```

## 仕様

### ゲーム概要

Pyxelを使用したプラットフォーマーゲームです。プレイヤーはランダムに生成されたプラットフォームを渡り、
画面右端のゴールを目指します。ステージをクリアするたびに難易度が上がり、ゴールの位置とプラットフォーム
のルートが再生成されます。

### ゲーム機能

#### プレイヤー操作
- **横移動**: 左向き矢印キーまたは A キーで左移動、右向き矢印キーまたは D キーで右移動
- **ジャンプ**: スペースキーで地面からジャンプ
- **壁ジャンプ**: 壁に接しながらスペースキーを押すと壁から飛び出す

#### ゲーム要素
- **プレイヤー**: 赤い矩形。横移動、ジャンプ、壁ジャンプができる
- **プラットフォーム**: 緑の矩形。プレイヤーが立つことができ、壁ジャンプに使用できる
- **ゴール**: 黄色い矩形。画面右端に配置される。ゴール到達でステージクリア

#### 物理エンジン
- **重力**: 毎フレーム 0.4 px のダウンフォース
- **最大落下速度**: 8.0 px/フレーム
- **ジャンプ力**: 初速度 5.0 px/フレーム（上向き）
- **移動速度**: 3.0 px/フレーム

#### ステージ進行
- 各ステージでプラットフォームはランダムに生成される
- ステージが進むたびに難易度が上昇（プラットフォーム間隔が広がる）
- 画面下に落ちるとステージがリセットされる

### 実装モジュール

#### `platformer/player.py`
`Player` クラスでプレイヤーキャラクターの状態管理と物理演算を実装
- 位置、速度の管理
- ジャンプ機能
- 壁ジャンプ機能
- 衝突判定用の境界ボックス取得

#### `platformer/platform.py`
`Platform` クラスでプラットフォーム（足場）を管理
- プラットフォームの配置と衝突判定
- 4方向からの衝突判定（上面：着地、下面：天井、左面：右側の壁、右面：左側の壁）

#### `platformer/level.py`
`Level` クラスでゲームステージ（レベル）を管理
- ランダムなプラットフォーム生成アルゴリズム
- プレイヤー能力に合わせたプラットフォーム難易度調整
- ゴール配置と判定

#### `platformer/game.py`
`Game` クラスメインゲームループの管理
- Pyxel統合
- 入力処理
- 衝突判定と物理応答
- 描画処理
- ステージ進行管理

## 修正履歴

### バージョン 0.1.1（2026年3月30日）

#### 修正内容

1. **ゴール判定の修正**
   - ゴールプラットフォームを着地判定から除外
   - ゴール着地時にプレイヤーが立つ判定をされないようにして，独立したゴール判定を有効化

2. **ゴール表示の改善**
   - ゴールをフレーム毎に点滅させ，目立つようにした
   - ゴール上部に「Goal!」テキストを表示

3. **ジャンプ高度の調整**
   - 初回調整：ジャンプ力を 10.0 → 3.3 px/フレーム に低減
   - 最終調整：ジャンプ力を 3.3 → 5.0 px/フレーム に調整
   - より細かいプラットフォーム配置が可能になり，ゲームバランスが向上

4. **ステージの動的再生成**
   - 起動のたびに異なる地形が自動的に生成される（ランダムシード使用）
   - リトライ時（画面外に落ちた時）は地形を保持し，同じステージを再挑戦できる
   - 次のステージに進むたびに新しい地形が生成される

#### 修正内容

1. **壁ジャンプ入力方向を逆転**
   - 壁ジャンプ判定の入力方向を逆に変更（左壁で右入力、右壁で左入力）
   - これによりユーザー指定の挙動に正式対応

### バージョン 0.1.7（2026年3月30日）

#### 修正内容

1. **壁ジャンプの連続実行を可能に**
   - ずり落ちている最中でも壁に向かって横入力しながらスペースキーを押すと壁ジャンプするように修正
   - `wall_jump()` メソッドで `is_jumping` を `True` に設定しないように変更
   - 壁ジャンプ後もすぐに次の壁ジャンプが可能になり、空中でのジャンプ制約を回避

2. **入力タイミングの改善**
   - 更新処理で横移動を先に処理し、プレイヤー位置更新・衝突判定後にジャンプ入力を処理するように改修
   - 壁に接触した直後にスペースキーを押しても、壁ジャンプが確実に発生するようになった

### バージョン 0.1.6（2026年3月30日）

#### 修正内容

1. **壁衝突判定の境界条件を拡張**
   - `is_colliding_from_left` の判定を `x2 + w2 >= x1` に変更
   - `is_colliding_from_right` の判定を `x2 <= x1 + w1` に変更
   - 壁にぴったり接した状態でも壁判定が取れ、壁ジャンプが発生しやすくなった

1. **着地判定の条件修正**

### バージョン 0.1.4（2026年3月30日）
