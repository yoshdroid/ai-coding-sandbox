# Platformer Game

このプロジェクトはPythonで実装するプラットフォーマーゲームです。

## 概要

プラットフォーマーゲームの基本的な機能をPythonで実装します。各関数に対してテストを作成し、テスト実行を学びます。

## セットアップ

1. Python 3.8以上をインストールしてください。

2. 依存関係をインストール：

   ```bash
   pip install -e .
   ```

3. テストを実行：

   ```bash
   pytest
   ```

4. ゲームを実行：

   ```bash
   python -m platformer.game
   ```

## 仕様

### ゲーム概要

Pyxelを使用したプラットフォーマーゲームです。プレイヤーはランダムに生成されたプラットフォームを渡り、
画面右端のゴールを目指します。ステージをクリアするたびに難易度が上がり、ゴールの位置とプラットフォーム
のルートが再生成されます。

### ゲーム機能

#### プレイヤー操作
- **横移動**: 左向き矢印キーまたは A キーで左移動、右向き矢印キーまたは D キーで右移動
- **ジャンプ**: スペースキーで地面からジャンプ
- **壁ジャンプ**: 壁に接しながらスペースキーを押すと壁から飛び出す

#### ゲーム要素
- **プレイヤー**: 赤い矩形。横移動、ジャンプ、壁ジャンプができる
- **プラットフォーム**: 緑の矩形。プレイヤーが立つことができ、壁ジャンプに使用できる
- **ゴール**: 黄色い矩形。画面右端に配置される。ゴール到達でステージクリア

#### 物理エンジン
- **重力**: 毎フレーム 0.4 px のダウンフォース
- **最大落下速度**: 8.0 px/フレーム
- **ジャンプ力**: 初速度 5.0 px/フレーム（上向き）
- **移動速度**: 3.0 px/フレーム

#### ステージ進行
- 各ステージでプラットフォームはランダムに生成される
- ステージが進むたびに難易度が上昇（プラットフォーム間隔が広がる）
- 画面下に落ちるとステージがリセットされる

### 実装モジュール

#### `platformer/player.py`
`Player` クラスでプレイヤーキャラクターの状態管理と物理演算を実装
- 位置、速度の管理
- ジャンプ機能
- 壁ジャンプ機能
- 衝突判定用の境界ボックス取得

#### `platformer/platform.py`
`Platform` クラスでプラットフォーム（足場）を管理
- プラットフォームの配置と衝突判定
- 4方向からの衝突判定（上面：着地、下面：天井、左面：右側の壁、右面：左側の壁）

#### `platformer/level.py`
`Level` クラスでゲームステージ（レベル）を管理
- ランダムなプラットフォーム生成アルゴリズム
- プレイヤー能力に合わせたプラットフォーム難易度調整
- ゴール配置と判定

#### `platformer/game.py`
`Game` クラスメインゲームループの管理
- Pyxel統合
- 入力処理
- 衝突判定と物理応答
- 描画処理
- ステージ進行管理

   - ゴール位置の高さを3パターンからランダムに選択：

     - 中：画面中央付近
     - 上：画面上から60px付近
   - スタート位置とゴール位置は独立してランダム化

   - プレイヤーの垂直ジャンプ能力（⬇jump_reachable_height ≈ 31.25px）を超える高さの場合、中間プラットフォームを自動生成
   - 目安：ゴールとプレイヤー現在位置の高さ差が `jump_reachable_height * 1.2` を超える場合
   - 水平足場を段階的に追加し、段々と上昇させることで全ゴールに到達可能

   - 登用壁は `screen_width - 150` に配置し、プレイヤーの現在位置からゴール位置までカバー
   - 壁 jump を駆使してプレイヤーが高い目標に到達可能に
   - Platform の `orientation="vertical"` で視認性向上

5. **テストスイートの拡充と修正**
   - `test_level_start_and_goal_reachable`: スタート・ゴール位置が入れ替わっても補助プラットフォームで到達可能か確認
   - `test_level_goal_climbing_wall_present_when_high`: ゴール位置が高い場合、登用壁が確実に生成されるか検証
   - ゴール配置ロジック全体の信頼性向上

#### 技術的ハイライト

- **到達可能性保証アルゴリズム**：
  - `jump_reachable_height = jump_power^2 / (2 * gravity) = 5.0^2 / (2 * 0.4) ≈ 31.25px`
  - このパラメータを中心に、補助プラットフォームと登用壁を戦略的に配置
  
- **ランダム化の独立性**：
  - スタート地点とゴール地点の高さは独立して3パターンから選択
  - 9通りのバリエーション（3×3）が自動的に生成される

- **完全な自動生成**：
  - プレイヤーが常に地上から開始（`start_platform` に配置）
  - すべてのゴール位置が必ず到達可能（補助プラットフォームまたは登用壁で対応）
  - 人手を介さない完全自動化で無限にプレイ可能
