# Random Platformer

Pyxel で動作する、ランダム生成ステージ式のプラットフォーマーゲームです。`DesignSpec.txt` の要件に沿って、タイトル画面、ゲーム画面、エンディング画面を持つ 10 ステージ構成で実装しています。

## 特徴

- ステージごとに異なる足場をランダム生成
- 足場は重ならないように配置
- 左右移動、ジャンプ、落下を含む基本的なプラットフォームアクション
- 画面下に落ちた場合のリスタート
- ゴール到達による次ステージ遷移
- `R` キーで同一ステージを再実行
- `S` キーで現在のステージをスキップ

## ディレクトリ構成

- `src/platformer/`
  ゲーム本体
- `tests/`
  pytest による自動テスト
- `DesignSpec.txt`
  実装元の設計書
- `ChangeLog.md`
  改修履歴

## セットアップ

```bash
cd with_designspec
pip install -e .
```

## 起動方法

```bash
python -m platformer
```

## テスト

```bash
pytest
```

## 操作方法

- 左右カーソルキー: 移動
- スペースキー: ジャンプ
- `R`: 現在のステージをリスタート
- `S`: 現在のステージをスキップ
