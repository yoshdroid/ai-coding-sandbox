# Platformer Game

Pyxel を使用した横スクロールプラットフォーマーゲームです。

## 機能

- タイトル画面、ステージゲーム、エンディング画面のシーン遷移
- 各ステージでランダムに生成される地形
- プレイヤー移動: カーソルキー左右で移動、スペースでジャンプ
- 壁ジャンプメカニクス
- ステージ進行: ゴールに到達して次ステージへ、10ステージクリアでエンディング
- R キーで現在のステージ再実行、S キーで新しいステージ開始

## 要件

- Python 3.8+
- Pyxel
- pytest (テスト用)

## インストール

1. リポジトリをクローン:
   ```bash
   git clone <repository-url>
   cd platformer
   ```

2. 依存関係をインストール:
   ```bash
   pip install -e .
   ```

## ゲームの実行

```bash
python -m platformer
```

## テスト

pytest でテストを実行:

```bash
pytest
```

## 操作方法

- 左右カーソルキー: 移動
- スペース: ジャンプ
- R: 現在のステージ再実行
- S: 新しいステージ開始

## 開発

このプロジェクトは pytest を使用したテスト駆動開発に従っています。テストコードには日本語コメントが含まれています。
