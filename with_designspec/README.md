# Random Platformer

Pyxel で動作する、ランダム生成ステージ式の横スクロールプラットフォーマーゲームです。`DesignSpec.txt` の要件に沿って、タイトル画面、ゲーム画面、エンディング画面を備えた 10 ステージ構成で実装しています。

## 特徴

- ステージごとに異なる地形を決定的にランダム生成
- 横長の足場に加えて、縦方向に細長い足場も生成
- 左右移動、ジャンプ、落下、着地を含む基本アクション
- 壁に向かって入力しながらジャンプすると壁ジャンプ可能
- 画面下へ落ちた場合はそのステージをリスタート
- ゴール到達で次ステージへ進行し、10 面クリアでエンディング
- `R` キーで同一ステージ再実行、`S` キーでステージスキップ

## ディレクトリ構成

- `src/platformer/`
  ゲーム本体
- `tests/`
  pytest による自動テスト
- `DesignSpec.txt`
  実装元の設計書
- `ChangeLog.md`
  改修履歴

## セットアップ

```bash
cd with_designspec
pip install -e .
```

## 起動方法

```bash
python -m platformer
```

## テスト

```bash
python -m pytest
```

## 操作方法

- 左右カーソルキー: 移動
- スペースキー: ジャンプ
- 壁に接触中に壁方向へ入力しながらスペースキー: 壁ジャンプ
- `R`: 現在のステージをリスタート
- `S`: 現在のステージをスキップ
