# Pyxel MCP Setup (GitHub-Copilot-Chat)

このプロジェクトは、Pyxel と Pyxel MCP を使ってゲーム開発と自動テストを行うためのサンプル構成です。

## 1. 依存関係のインストール

```bash
cd <local dir.>/ai-coding-sandbox/GitHub-Copilot-Chat
python -m pip install -r requirements.txt
```

## 2. 直接実行（Pyxelアプリ）

### オリジナルゲーム
```bash
python game.py
```
- 矢印キーで黄色（?緑色ぽくない?）の円を移動できます。

### ブロック崩しゲーム（パステルカラー版） 3/29
```bash
python breakout_game.py
```
- **矢印キー左右**: パドルを移動
- **Q キー**: ゲーム終了
- **R キー**: 再スタート（ゲームオーバー時）
- パステルカラーで統一した淡い見た目のブロック崩しゲーム
- 全ブロックを消すとゲームクリア
- ボールが画面下に落ちるとゲームオーバー

### シンプルプラットフォーマーゲーム 3/29
```bash
python platformer_game.py
```
- **矢印キー左右**: プレイヤーを移動
- **スペースキー**: ジャンプ（地面から）または壁ジャンプ（プラットフォームの側面から）
- **Rキー**: 現在のステージからリトライ（プレイヤーをスタート位置に戻す）
- ゴールを固定し、そこに向かう足場を自動生成。プレイヤーのジャンプ能力を考慮して到達可能な位置に配置。
- 画面左右端に壁があり、通れないが壁ジャンプはできない。
- 全4ステージ。後半2ステージ（3-4）では赤いスパイク（障害物）が登場。触れると自動リトライ。
- 難易度：自動生成によりバランス調整済み

## 3. Pyxel MCP ツールの実行例

Pyxel MCP の `run_and_capture` を使ってスクリーンショットを取得:

```bash
python mcp_test.py
```

- 成功すれば `out.png` が生成されます。

## 4. pyxel_info チェック

```bash
python -c "from pyxel_mcp.server import mcp; import asyncio; print(asyncio.run(mcp.call_tool('pyxel_info', {})))"
```

### 追加: プラットフォーマーゲーム開発履歴

**ユーザー:**  
あらたに Pyxelを使ってシンプルなプラットフォーマーゲームを作ってください。ジャンプ、壁ジャンプを基礎とした移動方法を使用し、難易度は簡単にまとめてください。

**開発過程:**  
1. **初期作成**: Pyxelを使ってシンプルなプラットフォーマーゲームを作成。基本的なジャンプと壁ジャンプの移動方法を実装。難易度は簡単なシングルステージ。

2. **壁ジャンプの改良**: 壁ジャンプを画面端ではなく地形（プラットフォーム側面）で発生するように変更。地形に横向きの衝突判定を追加。

3. **ゴール判定の追加**: ゴールに触れるとゲームクリアになる判定を実装。

4. **マルチステージ化**: 全3ステージに拡張。ゴール到達で次のステージへ自動移行。

5. **リトライ機能**: Rキーを押すと現在のステージからリトライ可能。

6. **ステージ拡張と障害物**: ステージ数を4つに増加。序盤の足場数を減らし、縦向き足場を追加。後半ステージにスパイク（触れるとリトライ）障害物を配置。

7. **自動生成システム**: ゴールを固定位置に設定し、そこに向かう足場を自動生成。プレイヤーのジャンプ能力を考慮して到達可能な位置に配置。画面左右端に壁を追加（通り抜け不可、壁ジャンプ不可）。

**最終結果:**  
これらの変更により、ゲームはシンプルながらも戦略性のある楽しいプラットフォーマーゲームになりました。Pyxelの基本機能を活かしつつ、衝突検出や自動生成などの技術的挑戦も盛り込まれています。
